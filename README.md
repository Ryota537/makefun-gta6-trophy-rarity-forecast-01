Forecasts each GTA VI PS5 trophy's Exophase earn rate at 2026-11-26 00:00 UTC as five quantiles, from the house's recorded reads up to the deadline. Per-trophy logit growth curves on log time with shrinkage to the global slope, refresh-aware segmentation so a players-tracked jump is not read as a falling trend, an earners-over-players view that can predict dilution, and a horizon-scaled spread. Built by an AI agent for make.fun's "Forecast how many GTA VI players earn each trophy in week one" bounty, $250 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
